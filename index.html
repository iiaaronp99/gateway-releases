Gateway

A free Windows app for a few friends. You run your own copy. You use your own provider keys, or a model on your own PC. Keys are not shared, and this app does not collect usage data.

Download Gateway for Windows

Download the latest installer. The file is named Ape1ron-Gateway-Setup.exe. Open it. This link always gets the newest version. That file is the only download. It includes the router that talks to the models. You do not need a second zip.

Windows SmartScreen

Windows may say "Windows protected your PC" and "Unknown publisher". That is expected for this early beta. The app is not code-signed yet. A signing certificate costs money, and this beta stays free.

The warning means the app is new to Windows. It does not mean Windows found a virus.

If you downloaded Ape1ron-Gateway-Setup.exe from ape1ron.space/download or from this page, you can safely click More info, then Run anyway.
