Gateway

A free Windows app for a few friends. You run your own copy. You use your own provider keys, or a model on your own PC. Keys are not shared, and this app does not collect usage data.

Download Gateway for Windows

Download the latest installer. The file is named Ape1ron-Gateway-Setup.exe. Open it. This link always gets the newest version.

Windows SmartScreen

The app is not signed. A signing certificate costs money, and this beta stays free. Windows may say "Windows protected your PC". Click More info, then Run anyway.

Friend guide

Read the friend guide. It covers installing Gateway, starting it, adding your own keys, connecting other tools, and Odyssey Journal.

Gateway bundle

The installer is the chat window. The gateway that talks to the models is a separate zip, because the app project is private. Download the gateway bundle. It has no secrets in it. The guide says which clicks come next.

Connect other apps

Setup for Cursor, Continue, Cline, Open WebUI, Aider, LangChain, and other OpenAI-style tools.
